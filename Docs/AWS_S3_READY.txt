STEP 1: Configure AWS CLI
──────────────────────────
Run this command and enter your AWS credentials:

    aws configure

You'll need:
  • AWS Access Key ID
  • AWS Secret Access Key  
  • Default region (use: us-east-1)
  • Default output format (use: json)

📌 Don't have AWS credentials?
   → Go to: https://console.aws.amazon.com/iam/
   → Create a new user with S3 access
   → Download credentials
   → See AWS_S3_SETUP_GUIDE.md for details


STEP 2: Run Automated Setup
────────────────────────────
After configuring AWS CLI, run:

    cd /Users/ilyessmoudden/Documents/Insite/Map
    ./setup-aws-s3.sh

This will automatically:
  ✅ Create S3 bucket: insite-data-storage
  ✅ Configure public access
  ✅ Set CORS policy
  ✅ Upload all 83+ data files (~140 MB)
  ✅ Display example URLs

Time: 5-10 minutes


STEP 3: Update Your App
────────────────────────
The script will tell you when to:
  1. Replace cloud-config.js with aws-s3-config.js
  2. Change INSITE_CLOUD_CONFIG to INSITE_S3_CONFIG
  3. Test your application
